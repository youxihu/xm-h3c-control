# 路由器端口映射快速切换工具

基于 Vue3 + Element Plus 开发的路由器端口映射管理工具。

## 功能特性

- 🚀 支持3个外网端口的快速切换（61002、61100、48099）
- 🎯 每个端口可在指定的内网IP之间切换
- 💡 直观的卡片式界面设计
- 📱 响应式布局，支持移动端
- ⚡ 实时显示当前映射状态

## 端口映射规则

- **端口 61002**: 可在 192.168.1.109（开发）和 192.168.1.94（测试）之间切换
- **端口 61100**: 可在 192.168.1.109（开发）和 192.168.1.94（测试）之间切换  
- **端口 48099**: 可在 192.168.1.109（开发）和 192.168.1.116（测试）之间切换

## 开发环境

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build
```

## 技术栈

- Vue 3
- Element Plus
- Vite
- 自动导入插件
